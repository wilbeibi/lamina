# The second note

A short note that exists so the first one has something to link to. Hovering a link to this page shows this paragraph.

## Method

Each heading becomes an anchor; hovering a link to an anchor shows the heading and this first paragraph under it. Anchors are the heading text with spaces turned into dashes, so `second-note.html#Method` works and Chinese headings keep their text.
